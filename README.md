# Introduction
This new component is designed for Group Treasurers, and aims to reduce their admin burden. Wherever possible tasks can be carried out from the front end of the website. 

The first function helps manage receipts from Members who are paying for Events. A list is shown of all outstanding payments, and the receipt of a payment can be recorded simply by clicking a button. This will:
 - Remove the entry from the list
  - Update the count of confirmed places 
 - Send a confirmation email to the member (with a copy to the Organiser)

Also available:
 - a searchavle list of all payments that have been made
 - a list of the future bookable Events
 - for any Event, a summary report is available, listing the individual payments in date order, and the total of all payments 
  - a searchable back-end function for correcting data entry errors and making refunds
# Future functionality
Support is planned for expense claims, so a member can log on the the website and make a claim by filling in a simple form, which would then be logged and passed to the Treasurer
